# Development
`pnpm@10` is required for this project.
- Install packages
```
pnpm install
```
You might need to manually allow `electron-winstaller` to install. pnpm blocks running scripts by default.
```
pnpm approve-builds
```

- Start dev server
```
pnpm run dev
```
